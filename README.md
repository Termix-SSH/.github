# Overview

This repo holds the Termix organization profile, shown at [github.com/Termix-SSH](https://github.com/Termix-SSH), and the defaults every repo without its own copy uses: `SECURITY.md`, `CONTRIBUTING.md`, `SUPPORT.md`, the funding link in `.github/FUNDING.yml`, the pull request template and the issue forms in `.github/ISSUE_TEMPLATE` (which is what every plugin repo shows). The profile is in `profile/README.md`.

# Support

Every repo handles its own issues. See [SUPPORT.md](SUPPORT.md) for where to open one. You can also ask in the [Discord](https://discord.gg/jVQGdvHDrf) server.
