# Getting help with Termix

Every Termix repo handles its own issues. Open yours on the repo the problem is about.

| What it's about | Where to open it |
| --- | --- |
| Termix itself: login, users, hosts, credentials, sharing, sync, settings, the web and desktop app | [Termix-SSH/Termix](https://github.com/Termix-SSH/Termix/issues/new/choose) |
| A plugin: terminal, file manager, Docker, remote desktop, tunnels, metrics, SSO and so on | That plugin's `Plugin-<Name>` repo. Every official plugin is listed in the [Termix README](https://github.com/Termix-SSH/Termix#plugins) |
| The iOS or Android app | [Termix-SSH/Mobile](https://github.com/Termix-SSH/Mobile/issues/new/choose) |
| The command line tool | [Termix-SSH/CLI](https://github.com/Termix-SSH/CLI/issues/new/choose) |

Not sure where it goes? Open it on [Termix-SSH/Termix](https://github.com/Termix-SSH/Termix/issues/new/choose) and it will be moved to the right repo.

## The fastest way to report a plugin bug

Open the plugin's page in the **Plugins** tab in Termix and press **Report an issue**. It opens the bug form on the right repo with your Termix version, plugin version, environment and any plugin error already filled in.

## What to include

- What happened and what you expected
- Steps to reproduce it
- Your Termix version (Settings, About), and the plugin version if it's a plugin
- Logs: the browser console, or `docker logs termix`

Please write in English if you can. Search open and closed issues first.
